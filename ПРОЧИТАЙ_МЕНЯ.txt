MAVIS · Зарплата из Bitrix24 — исправление источника оплат

В репозитории https://github.com/mavisgroupiishki-alt/mavis-operational-dashboard
заменить файлы с сохранением путей:

app/main.py
app/cabinet_payroll.py (новый файл, если еще не установлен)
app/static/cabinet.html
app/static/cabinet-payroll.js (новый файл, если еще не установлен)
app/static/cabinet-upgrade.js (нужен для существующего интерфейса кабинета)

Никаких Excel/JSON с оплатами в GitHub не загружать.

Логика:
1. Вкладка «Зарплата» автоматически получает закрытые успешные сделки из Bitrix24
   по ответственному менеджеру и CLOSEDATE за выбранный месяц.
2. Источник — стадии «Предоплата получена» и «Продажа успешна».
   Отказы и прочие закрытия не импортируются.
3. Товары берутся из товарных строк сделок через Bitrix24; можно выбрать «Только подборы».
4. «Сравнить с Bitrix24» показывает новые сделки, расхождения в суммах и записи только
   в личном отчете; «Подтянуть новые сделки» добавляет недостающие, НЕ перезаписывая правки.
5. Запись о закрытии сделки — НЕ доказательство оплаты банком. Новые записи имеют
   статус «На проверке», для зарплаты требуется подтверждение руководителя.
6. Сетку Алёны, планы, оклад и отсутствия можно менять в закрытом кабинете.

ВАЖНО: эта схема сопоставляет одну строку отчёта с одним ID сделки и суммой сделки.
Если по одной сделке было несколько отдельных оплат, нужна расширенная сверка с
графиком платежей/банковским реестром. В таком случае разница будет показана,
а не автоматически принята как ошибка менеджера.

Перед публикацией проверьте, что в GitHub остальные файлы сервиса обновлены.
Render с автодеплоем подхватит новый коммит.
