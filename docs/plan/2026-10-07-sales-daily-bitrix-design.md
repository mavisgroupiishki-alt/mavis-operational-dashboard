# Ежедневный отчёт продаж из Bitrix

## Решение

Вместо встраивания недоступного BI-конструктора дашборд получает дневные данные напрямую из Bitrix24. Это устраняет зависимость от браузерной сессии BI и сохраняет привычный дизайн дашборда.

## Пользовательский путь

1. Руководитель открывает «Продажи».
2. Внутри раздела выбирает «Ежедневный отчёт» и день.
3. Открывает «Лиды и сделки» либо «Звонки».
4. Сверяет результаты за 30.09.2026 с прежним скриншотом BI.

## Границы достоверности

Показатели создания лидов и сделок, источники, менеджеры, клиентский тип, количество и длительность звонков доступны как дневные записи CRM. Исторический остаток воронки «на конец дня» не будет имитироваться из текущих карточек: без подтверждённой истории стадий интерфейс явно покажет ограничение.

## Обработка ошибок

Каждый блок имеет статус доступности. Если Bitrix не вернул активность звонка или она не содержит направления/длительности, запись учитывается в «Не классифицировано», а не превращается в ноль или в произвольный тип звонка.
