# Архив ежедневного отчёта продаж

## Решение

Сегодня дашборд читает Bitrix24 онлайн. После полуночи он сохраняет один неизменяемый отчёт за вчерашний день. Архивный день больше не получает новые данные Bitrix и поэтому не меняется от поздних исправлений карточек, источников или сотрудников.

## Режимы данных

- **Онлайн** — только для текущего дня; данные читаются непосредственно из Bitrix24.
- **Архивный снимок** — для дня, который система успешно зафиксировала; отображается время создания снимка.
- **Текущий вид CRM для прошлого дня** — честный fallback для старых дат без архива; интерфейс предупреждает, что это не исторический срез.

## Граница точности

Первые неизменяемые снимки появятся после публикации этой функции. Сентябрьский BI‑снимок нельзя восстановить из текущих карточек CRM: их источники и связи могли измениться после 30 сентября.

## Надёжность

Веб‑процесс выполняет фиксацию в окне 00:10–00:59 по времени дашборда. Для абсолютной гарантии при остановленном веб‑сервисе понадобится отдельный Render Cron Job; его создание не включено, так как Render взимает минимум $1/месяц за такой сервис и cron не может пользоваться текущим диском.
