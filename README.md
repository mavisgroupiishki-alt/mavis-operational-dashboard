# MAVIS Operational Dashboard v2.4

Рабочая версия дашборда Mavis Group для Render + Bitrix24 + Supabase.

## Что нового в v2.4

- Новый светлый интерфейс: серо-голубой фон, белые аналитические панели и цветовая кодировка отделов.
- Общий экран: крупный блок ОП + цветные сигнальные карточки производства, рисков, конверсии и NPS.
- Страницы Продажи и Производство получили отдельные управленческие hero-блоки.
- Расшифровка: 2 уровня группировки -> конкретные сделки; добавлены визуальные бары групп.
- Исправлена кнопка `Показать ещё`: данные догружаются страницами по 100 записей.
- NPS больше не пытается искать сделки: его вводит руководитель вручную.
- На странице Эксперты есть явные кнопки `+ Добавить эксперта из Bitrix` и `+ Внести NPS вручную`.
- На странице Продажи есть `+ Добавить менеджера`.
- Планы, комментарии, ручной NPS, команда и настройки зависших сохраняются в Supabase при наличии `SUPABASE_URL` + `SUPABASE_KEY`.

## Постоянное хранение — Supabase

1. Создать проект Supabase.
2. В SQL Editor выполнить `SUPABASE_SQL.sql`.
3. В Render -> Environment добавить:

```text
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_KEY=<server secret / service_role key>
```

После redeploy открой `/health`. Поле `storage` должно быть `Supabase`.

Важно: `SUPABASE_KEY` используется только backend и никогда не должен попадать в GitHub или frontend.

## Render Free

`render.yaml` рассчитан на Free Web Service и НЕ содержит persistent disk. После перехода на Supabase диск Render не нужен.

Если сервис был создан раньше с Starter + Disk, существующий сервис может не понизиться автоматически после изменения `render.yaml`. В Render Dashboard нужно вручную удалить persistent disk и выбрать Free instance.

## Bitrix

Фактические данные всегда читаются из Bitrix. Supabase хранит только ручные/настроечные данные:

- планы;
- комментарии к KPI;
- NPS руководителя;
- выбранные менеджеры;
- выбранные эксперты;
- критерии зависших;
- mappings/settings.

## Проверка

```text
/health
```

Должно быть примерно:

```json
{"ok":true,"version":"2.4.0","storage":"Supabase"}
```
