# Спецификация: Рабочий канбан проектов

**ID:** 006-task-kanban-flow  **Статус:** Approved  **Создана:** 2026-09-25

## Цель

Сделать проектный экран задач полноценной рабочей доской: с достаточным числом стадий, переносом карточек и быстро сохраняемыми представлениями.

## Функциональные требования

1. Канбан проекта ДОЛЖЕН содержать стадии: «Бэклог», «Новая», «Запланирована», «В работе», «Ожидание», «На проверке», «Готово», «Завершена».
2. Бэклог ДОЛЖЕН быть самостоятельной первой колонкой. Существующие задачи с признаком бэклога ДОЛЖНЫ открываться в ней.
3. Пользователь ДОЛЖЕН иметь возможность перетащить карточку на другую колонку на desktop; перенос ДОЛЖЕН сохранять новую стадию.
4. На iPhone должен оставаться доступный способ смены стадии через карточку задачи.
5. В проекте ДОЛЖНЫ быть быстрые виды «Мои», «Просроченные», «На этой неделе» и возможность сохранить текущие фильтры под собственным названием.
6. Пользователь ДОЛЖЕН иметь возможность удалить собственный сохранённый вид.
7. Канбан ДОЛЖЕН стать визуально более контрастным: цветные заголовки стадий, заметные карточки и понятные состояния переноса при сохранении существующего MAVIS-стиля.
8. Стадия и сохранённые виды ДОЛЖНЫ переживать обновление страницы и развёртывание.

## Вне скоупа

- Создание, изменение или перенос задач Bitrix24.
- Настройка произвольных названий стадий в этой итерации.

## Критерии приёмки

- [x] Перетаскивание карточки меняет её стадию и сохраняется после обновления.
- [x] Бэклог показан самостоятельной первой колонкой.
- [x] Быстрые и именованные сохранённые виды работают внутри выбранного проекта.
- [ ] Канбан читабелен на desktop и iPhone без горизонтальной обрезки страницы (нужна проверка на реальном iPhone после публикации).
