# Технический план: Аудит CRM в операционном дашборде

**Спека:** [spec.md](spec.md)  **Создан:** 2026-09-10

## Технологии

Flask-служба Jarvis получает read-only данные Bitrix24 и передаёт ограниченный JSON через существующий защищённый маршрут. FastAPI-дашборд проксирует JSON без передачи секрета браузеру. Браузер отображает сводку и таблицу.

## Архитектура

```
Bitrix24 read-only API -> Jarvis audit exporter -> dashboard server proxy -> CRM audit view
```

## API / интерфейсы

- `GET /api/integrations/operations/crm-audit` — JSON с `summary`, `funnelBreakdown`, `details`, `generatedAt`.
- `GET /api/crm-audit` — существующий защищённый серверный прокси.
- Раздел «Аудит CRM» — вкладки «Сводка» и «Карточки для проверки».

## Риски

- Объём CRM требует ограничения ответа и кэширования расчёта.
- История ежедневных срезов требует отдельно настроенного постоянного хранилища и расписания; первый релиз не должен притворяться историческим, если оно не подключено.

## Проверка конституции

- [ ] Метрики и названия соответствуют существующей таблице.
- [ ] Интеграция не изменяет Bitrix24 и не отправляет секрет в браузер.
