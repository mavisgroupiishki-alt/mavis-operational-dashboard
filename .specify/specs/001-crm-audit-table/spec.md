# Спецификация: Аудит CRM в операционном дашборде

**ID:** 001-crm-audit-table  **Статус:** Approved  **Создана:** 2026-09-10

## Цель

Показать в операционном дашборде существующий ежедневный аудит CRM без изменения его показателей и состава карточек.

## Пользовательские истории

- Как РОП, я хочу видеть ежедневные показатели аудита CRM и изменения к предыдущему срезу.
- Как РОП, я хочу открыть список карточек для проверки, отфильтровать его и перейти в исходную карточку Bitrix24.
- Как руководитель, я хочу видеть распределение активных сделок по воронкам.

## Функциональные требования

1. Система ДОЛЖНА рассчитывать метрики существующей таблицы для всех активных сделок и открытых лидов.
2. Система ДОЛЖНА включать проблемы: нет источника, нет последней коммуникации, нет контакта и компании, сделка в воронке «Зависшие», неактивный владелец и открытый лид без контакта и компании.
3. Система ДОЛЖНА возвращать одну строку на одну проблему карточки с датой среза, приоритетом, воронкой, типом, ID и безопасной ссылкой Bitrix24.
4. Дашборд ДОЛЖЕН показывать ежедневный свод, распределение по воронкам и фильтруемый список карточек.
5. Дашборд ДОЛЖЕН показывать дату последнего успешного среза и не подменять недоступный источник нулевыми значениями.

## Вне скоупа

- Изменение карточек, полей или роботов Bitrix24.
- Создание или пересчёт Health Score.
- Перенос маркетингового приложения и интерфейса Jarvis.

## Критерии приёмки

- [ ] API возвращает согласованные метрики, разрез воронок и ссылки карточек без секретов.
- [ ] В интерфейсе доступны сводка и список карточек с фильтрами.
- [ ] Ссылка каждой строки открывает соответствующую карточку Bitrix24 в новой вкладке.
- [ ] Ошибка источника явно отображается пользователю.
