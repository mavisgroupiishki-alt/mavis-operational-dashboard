# Спецификация: Архив ежедневного отчёта продаж

**ID:** 016-sales-daily-archive
**Статус:** Approved
**Создана:** 2026-10-07

## Цель

Сохранить проверяемый неизменяемый снимок ежедневного отчёта продаж после закрытия дня, сохранив для текущего дня онлайн‑данные Bitrix24.

## Пользовательские истории

- Как руководитель продаж, я хочу открыть любой прошлый день и видеть зафиксированные на закрытие дня показатели, чтобы исторические отчёты не менялись из-за поздних правок CRM.
- Как руководитель продаж, я хочу видеть в интерфейсе, является ли отчёт онлайн‑данными или архивным снимком, чтобы не путать два режима.
- Как пользователь дашборда, я хочу честно видеть отсутствие архива для даты, которая не снималась системой, вместо подмены его текущими CRM‑данными.

## Функциональные требования

1. Текущий календарный день ДОЛЖЕН загружаться напрямую из Bitrix24 в онлайн‑режиме.
2. После наступления нового дня система ДОЛЖНА создавать один неизменяемый снимок предыдущего дня в часовом поясе дашборда.
3. Для дня, у которого существует снимок, API ДОЛЖЕН отдавать архивный снимок без повторного чтения Bitrix24.
4. Каждый ответ ДОЛЖЕН содержать режим данных, время снимка и понятное объяснение его происхождения.
5. Если у прошедшего дня архив не был создан, интерфейс ДОЛЖЕН показать текущие read-only данные Bitrix24 с предупреждением, что они могли измениться после выбранной даты.
6. Архив ДОЛЖЕН сохраняться в существующем долговременном хранилище дашборда и не перезаписываться повторными задачами.
7. Вся интеграция с Bitrix24 ДОЛЖНА оставаться server-side и read-only.

## Вне скоупа

- Восстановление точных архивных значений для дат, которые были до появления снимков.
- Создание платного ресурса Render без явного согласования пользователя.
- Изменение месячных KPI продаж или состава команды.

## Критерии приёмки

- [x] Сегодняшняя дата показывает режим «Онлайн».
- [x] Сохранённый день показывает режим «Архивный снимок» и не вызывает Bitrix.
- [x] Несохранённая прошедшая дата не маскируется под архив.
- [x] Повторная попытка сохранить тот же день не заменяет исходный снимок.
- [x] Данные и метки режима видны во вкладках «Лиды и сделки» и «Звонки».
