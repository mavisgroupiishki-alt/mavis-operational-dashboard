# Технический план: Быстрый старт операционного дашборда

**Спека:** `002-fast-startup`  **Создан:** 2026-09-11

## Технологии

FastAPI, текущий JSON snapshot, vanilla JavaScript и Render persistent disk `/var/data`.

## Архитектура

`/api/snapshot?compact=1` возвращает свод: у продаж остаются KPI, этапы и компактные строки менеджеров без глубоких деревьев. Новый `/api/sales-section` выдаёт полный объект продаж из того же кеша или persistent disk. Браузер показывает хаб после компактного snapshot, а тяжёлую разметку продаж строит только при открытии раздела.

## API

- `GET /api/snapshot?compact=1` — начальный компактный snapshot; без `compact` контракт остаётся прежним.
- `GET /api/sales-section` — полный объект `sales` для выбранного периода; возвращает `202`, если сервер ещё восстанавливает snapshot.

## Риски

- При смене периода в момент запроса нельзя подставить детали от предыдущего периода.
- Ручные настройки состава менеджеров и планы остаются частью компактного snapshot.

## Проверка конституции

- [ ] Источники Bitrix не меняются и остаются read-only.
- [ ] Недоступные детали явно показывают состояние загрузки, а не нули.
