# Спецификация: Ежедневные отчёты Telegram из BI-конструктора

**ID:** 013-telegram-bi-reports  **Статус:** Approved  **Создана:** 2026-10-02

## Цель

Автоматически формировать для руководителей два ежедневных текстовых отчёта и прикладывать к ним актуальный снимок дашборда «Ежедневный отчёт» из BI-конструктора Bitrix24.

## Пользовательские истории

- Как руководитель, я хочу получать в Telegram отчёты по продажам и экспертам без ручной публикации.
- Как руководитель, я хочу видеть именно актуальный экран BI-конструктора, а не заменённую картинку из другого дашборда.
- Как администратор, я хочу, чтобы учётные данные Bitrix и Telegram оставались секретами сервера Render.

## Функциональные требования

1. Сервис ДОЛЖЕН использовать серверную авторизацию Bitrix24, независимую от VPN на рабочем компьютере.
2. Сервис ДОЛЖЕН получать снимок страницы BI-конструктора `Ежедневный отчёт` (dashboard ID 80) только после успешной загрузки данных.
3. При недоступности отчёта сервис ДОЛЖЕН завершаться явной ошибкой и НЕ отправлять пустой, устаревший или сгенерированный вместо BI снимок.
4. Сервис ДОЛЖЕН строить текст отчётов из текущего server-side snapshot операционного дашборда.
5. Если план продаж или производства отсутствует, сервис ДОЛЖЕН явно показывать «—», а не переносить план из другого месяца.
6. Отправка в Telegram ДОЛЖНА быть доступна только серверному администратору и использовать токен из переменной окружения.

## Вне скоупа

- Публикация в Telegram-канал до добавления бота администратором канала.
- Ежедневное время автоматического запуска: время не согласовано.
- Изменение расчётов продаж и производства.

## Критерии приёмки

- [ ] При корректных секретах сервер получает PNG/JPG BI-отчёта ID 80.
- [ ] Тестовая команда отправляет в личный Telegram две текстовые сводки и снимок BI.
- [ ] При недоступности BI отправка не выполняется и возвращает понятную ошибку.
- [ ] Текст не содержит вымышленных планов или показателей.
