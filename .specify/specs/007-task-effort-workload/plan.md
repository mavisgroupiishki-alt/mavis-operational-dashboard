# Технический план: Трудозатраты и напоминания задач

**Спека:** `spec.md`  **Создан:** 2026-09-28

## Архитектура

Новые числовые значения хранятся в существующих записях задач dashboard storage. Сервер валидирует завершение независимо от клиента. Представление задач нормализует поля и вычисляет напоминания и часы выбранной календарной недели. Клиент добавляет компактные поля в редактор и выводит сводку без обновления всей страницы.

## Компоненты

| Блок | Файлы | Проверка |
|---|---|---|
| Хранение, проверка и вычисления | `app/storage.py`, `app/key_tasks.py` | unit tests |
| API и история изменений | `app/main.py` | API/unit tests |
| Форма, карточки, напоминания и нагрузка | `app/static/index.html`, `app/static/app.js`, `app/static/styles.css` | JS syntax, browser smoke test |

## Риски

- Старые задачи не содержат часов; они трактуются как `0`, но не считаются ошибочными, пока их не завершают заново.
- На touch-устройствах карточка уже открывается по нажатию; так же вводится факт часов перед завершением.
