# Спецификация: Трудозатраты и напоминания задач

**ID:** 007-task-effort-workload  **Статус:** Approved  **Создана:** 2026-09-28

## Цель

Помочь команде видеть предстоящую работу без внешних уведомлений: планировать часы при постановке задачи, фиксировать фактические часы при завершении и видеть напоминания и недельную нагрузку прямо в дашборде.

## Функциональные требования

1. У задачи ДОЛЖНЫ быть ручные поля «План, ч.» и «Факт, ч.»; существующие задачи без этих значений остаются доступными.
2. При переводе задачи в «Завершена» ДОЛЖНО требоваться положительное значение «Факт, ч.». Это правило действует как в форме, так и на сервере.
3. При перетаскивании карточки в «Завершена» дашборд ДОЛЖЕН открыть карточку задачи для ввода факта, а не молча завершить её.
4. На главном экране раздела «Задачи» ДОЛЖЕН быть блок «Требуют внимания»: просроченные, на сегодня и на ближайшие два дня. Нажатие открывает соответствующую задачу. Уведомления не отправляются вне дашборда.
5. В блоке «Нагрузка команды» для каждого активного сотрудника ДОЛЖНЫ отображаться: плановые часы по активным задачам со сроком в текущей календарной неделе и фактические часы по задачам, завершённым в текущей календарной неделе.
6. Неделя считается с понедельника по воскресенье в часовом поясе дашборда. Никакая предполагаемая норма рабочего времени и «перегруз» не выводятся без отдельной настройки пользователя.
7. Поля трудозатрат ДОЛЖНЫ отражаться в истории изменений задачи.

## Вне скоупа

- Автоматическая оценка часов ИИ или автоматическое назначение исполнителей.
- Push-, email-, Telegram- и другие внешние напоминания.
- Автоархив завершённых задач, изменение порядка карточек и настройка нормы часов.

## Критерии приёмки

- [ ] Пользователь может записать плановые часы при создании или редактировании.
- [ ] Нельзя сохранить задачу в статусе «Завершена» без фактических часов больше нуля.
- [ ] На экране задач видны понятные напоминания и недельные часы команды.
- [ ] Данные часов и напоминания сохраняются после обновления страницы.
