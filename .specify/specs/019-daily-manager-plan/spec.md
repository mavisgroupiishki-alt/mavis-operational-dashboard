# Спецификация: Единый ежедневный план менеджера

**ID:** 019-daily-manager-plan
**Статус:** Approved
**Создана:** 2026-11-04

## Цель

Сделать главный экран кабинета ежедневным планом действий, а не набором повторяющихся списков: менеджер видит, кому и почему позвонить сегодня, ключевые нормы и раскрываемую диагностику портфеля.

## Правило ИСО/СУОТ

Красный сигнал по сделке и звонку допускается только при всех подтверждённых условиях:

1. У компании есть корректный УНП, и ежедневный реестр не находит её **по этому УНП**.
2. В текущей сделке нет ИСО/СУОТ.
3. Среди предыдущих успешных продаж этой компании нет ИСО/СУОТ.
4. В связанном разобранном звонке Jarvis явно зафиксировал, что менеджер не предложил ИСО/СУОТ.

Отсутствие УНП, реестра, истории или разбора звонка не создаёт красный сигнал. Такие случаи могут быть показаны как нейтральный статус «недостаточно подтверждений».

## Функциональные требования

1. Вверху кабинета ДОЛЖЕН быть один раздел «План на сегодня» с приоритетными действиями и прямыми ссылками в Bitrix24.
2. Повторяющиеся списки подсказок, рисков и задач НЕ ДОЛЖНЫ конкурировать с главным планом; диагностические списки ДОЛЖНЫ быть сворачиваемыми.
3. Кабинет ДОЛЖЕН показывать:
   - долю активных сделок с назначенным следующим шагом и конкретной датой;
   - среднее время на каждом этапе против нормы этапа;
   - конверсию успешного звонка в назначенный следующий шаг;
   - прогноз выполнения месячного плана: фактический темп против нужного дневного темпа;
   - список сделок с документом/БИС, срок которого наступает в ближайшие 30 дней, только если дата явно есть в CRM-данных.
4. «Новые лиды» в кабинете означают только необработанные лиды на стадии «Новые».
5. У каждого показателя ДОЛЖНО быть понятное определение и статус «нет данных», если источник не передал необходимый факт.

## Критерии приёмки

- [ ] Красный ИСО/СУОТ-сигнал не возникает при одном лишь пустом поле услуги.
- [ ] Для подтверждённого сигнала доступны УНП, история услуги и результат анализа связанного звонка.
- [ ] Главный план не дублирует те же строки в трёх соседних блоках.
- [ ] Все пять новых показателей приходят с сервера и не вычисляются по выдуманным значениям в браузере.
- [ ] Списки SLA, ИСО/СУОТ, касаний и документов можно раскрыть по необходимости.
